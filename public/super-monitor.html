Emergency

Restarts the Node process via PM2. Expect all live classes to drop for roughly 5–10 seconds.

During concurrent-session tests: watch RAM (MB) — if it keeps climbing after classes end, investigate leaks (e.g. unclosed DB handles). If avg latency stays above ~500ms, teachers may notice lag; check server load and upstream network (e.g. Hostinger).
